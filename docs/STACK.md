# Stack tecnológica

## Backend
- **Java 21**
- **Spring Boot 3.5.16**
- **Spring Security** + **JWT** (JJWT 0.13.0)
- **JPA / Hibernate**
- Flyway (migrations)
- springdoc-openapi 2.8.17 (Swagger UI)

## Banco
- **PostgreSQL 16** (produção / Docker)
- H2 (apenas profile `local` para desenvolvimento)

## Front-end
- **React 18**
- **TypeScript**
- **Tailwind CSS**
- Vite, React Router, Axios

## Infra
- Docker Compose (postgres, backend, frontend, backup)
- Nginx (serve do frontend)
